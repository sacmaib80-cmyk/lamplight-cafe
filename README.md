# Lamplight Café

เกมฝึกพูดภาษาอังกฤษ: คืนฝนตก คุณเดินเข้าร้านกาแฟ แล้วต้องสั่งของให้ได้ด้วยภาษาอังกฤษกับพนักงานชื่อ Luna

**เล่นได้ที่:** https://sacmaib80-cmyk.github.io/lamplight-cafe/ (ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ เปิดเสียงไว้)

- พิมพ์ภาษาอังกฤษคุยกับ Luna ได้อิสระ: สั่งเครื่องดื่ม/ขนม ถามราคา ขอให้แนะนำ เปลี่ยนใจ ถามรหัส Wi-Fi ถามทางไปห้องน้ำ คุยเล่น
- Luna จำชื่อ จำสิ่งที่สั่ง และตอบต่างกันตามว่าเราพูดสุภาพแค่ไหน
- ปากกาแดงแก้ประโยคที่คนไทยพูดผิดบ่อย (I want → I'd like, ice latte → iced latte, I have 15 years old → I'm 15 years old)
- 3 ระดับ: คั่วอ่อน (มีคำแปลและประโยคตัวอย่าง) · คั่วกลาง (มีคำใบ้) · คั่วเข้ม (ไม่มีตัวช่วย)
- ไม่ใช้ AI ไม่มีค่าใช้จ่าย: สมองของตัวละครเขียนด้วยโค้ดทั้งหมด เสียงพูดใช้ระบบเสียงในเบราว์เซอร์

ฉาก ของในร้าน และเสียงประกอบสร้างด้วยโค้ดของโปรเจกต์นี้เอง · ตัวละครเป็นโมเดลของเจ้าของโปรเจกต์
